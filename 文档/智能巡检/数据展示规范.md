# 数据展示规范

> 适用范围：后台列表页、详情页、仪表盘、图表卡片、描述信息区、统计卡片、标签展示区。
> 目标：统一表格、图表、描述列表、数字、时间、百分比、状态标签、IP/主机名等数据展示方式，避免前端或 IDE 在展示层自由发挥。

## 0. 审阅标记说明

- `【新增】`：本次新增内容，建议重点审阅
- `【删除建议】`：建议后续从旧页面、旧组件、旧展示方式中移除或替换的内容

## 1. 总体原则

### 1.1 数据展示优先级

【新增】展示层必须遵循以下优先级：

1. 优先服从设计稿中的展示方式
2. 设计稿未定义时，服从本规范
3. 本规范未定义时，回报缺失信息，不允许页面自行决定

### 1.2 统一目标

【新增】数据展示不仅要求“能显示”，还必须满足：

1. 可读
2. 可对比
3. 可扫描
4. 可扩展
5. 与通用组件和状态文案规范一致

### 1.3 统一禁止项

【删除建议】以下做法不建议继续使用：

- 同一字段在不同页面有不同格式
- 同一种状态在表格、卡片、详情页中展示方式不一致
- 表格空值有时是 `-`，有时是 `/`
- 时间一会儿显示秒，一会儿不显示秒，没有规则
- 百分比有时保留 0 位，有时保留 2 位，没有规则

## 2. 表格展示规范

### 2.1 列配置最小要求

【新增】每一列至少应明确：

| 字段 | 说明 |
|------|------|
| `title` | 表头文案 |
| `dataIndex` | 数据字段 |
| `width` / `minWidth` | 列宽策略 |
| `align` | 对齐方式 |
| `renderType` | text / tag / status / link / action / number / date |
| `ellipsis` | 是否省略 |
| `emptyValue` | 空值展示规则 |

### 2.2 列内容类型规则

【新增】建议统一如下：

| 类型 | 展示规则 |
|------|------|
| 文本 | 默认左对齐 |
| 数值 | 默认右对齐 |
| 金额 / 风险分 / 百分比 | 默认右对齐 |
| 状态 | 使用 `StatusBadge` |
| 操作列 | 默认右对齐 |
| 日期时间 | 默认左对齐，格式统一 |
| 标签组 | 使用标签组件，不直接裸字符串拼接 |

### 2.3 超长文本规则

【新增】统一要求：

1. 主机名、模板名、任务名、策略名等主标识字段默认单行省略。
2. 省略文本默认展示 tooltip，除非设计稿明确要求换行。
3. 描述性长文本不建议放在表格主列表中直接完整展示。

【删除建议】不建议：

- 某些列自动换两行，导致整表行高被拉大
- 某些列不省略，撑爆布局
- 某些列省略但没有 tooltip

### 2.4 操作列规则

【新增】统一要求：

1. 操作列默认放在右侧。
2. 操作按钮不超过 3 个。
3. 超过 3 个时收敛到“更多”下拉。
4. 危险操作放在次级层级，不与主操作并列强调。

### 2.5 空值规则

【新增】统一要求：

| 数据类型 | 空值展示 |
|------|------|
| 文本 | `--` |
| 数值 | `--` |
| 百分比 | `--` |
| 时间 | `--` |
| 标签 | `--` |
| IP / 域名 | `--` |

### 2.6 分页展示规则

【新增】统一建议：

1. 分页器固定放在表格下方右侧。
2. 分页高度统一使用 `--comp-pagination-height`。
3. 切页、改 pageSize 后应保留当前筛选条件。

## 3. 图表展示规范

### 3.1 图表通用规则

【新增】图表必须明确以下信息：

| 项目 | 说明 |
|------|------|
| 图表类型 | 折线 / 柱状 / 饼图 / 雷达 / 网络图 / 趋势面积图 |
| 标题 | 图表卡片标题 |
| 图例位置 | 顶部 / 右侧 / 底部 |
| tooltip 内容 | 显示哪些字段 |
| 空态 | 无数据时如何展示 |
| 颜色映射 | 系列颜色顺序 |

### 3.2 图表颜色规则

【新增】统一建议：

1. 优先使用品牌主色和功能色。
2. 同一业务语义的系列颜色保持一致。
3. 红色系优先保留给风险、异常、失败。
4. 绿色系优先保留给成功、通过、正常。

### 3.3 图表空态规则

【新增】统一要求：

1. 图表无数据时显示空态组件或图表级占位。
2. 不允许只保留坐标轴或空白画布。
3. 空态文案统一复用《状态枚举与文案规范》。

### 3.4 tooltip 规则

【新增】统一建议：

1. tooltip 中字段顺序应与视觉顺序一致。
2. 数值字段保持与页面其他区域同样格式。
3. 时间字段格式与全局时间格式保持一致。

【删除建议】不建议：

- tooltip 与卡片正文用不同时间格式
- tooltip 中单位忽有忽无
- 图例文案和表格文案不一致

## 4. 描述列表 / 详情信息规范

### 4.1 使用场景

【新增】适用于详情页、卡片详情、基础信息区、任务摘要区。

### 4.2 展示规则

【新增】统一建议：

| 项目 | 规范 |
|------|------|
| label 对齐 | 左对齐 |
| value 对齐 | 左对齐 |
| label 宽度 | 同一区块内保持一致 |
| label/value 间距 | 使用统一 spacing token |
| 空值 | `--` |
| 长文本 | 根据设计稿决定换行或省略，但要统一 |

### 4.3 复制类字段

【新增】以下字段建议支持复制能力：

- IP 地址
- 主机名
- 任务 ID
- 模板 ID
- 风险规则编码

### 4.4 禁止项

【删除建议】不建议：

- label 宽度每行都不一样
- 同一区块部分字段右对齐、部分左对齐，没有规则
- 长文本直接顶开整个详情卡片

## 5. 数字展示规范

### 5.1 一般数值

【新增】统一建议：

| 场景 | 展示规则 |
|------|------|
| 计数值 | 默认不带小数 |
| 指标值 | 按业务定义决定是否保留小数 |
| 大数字 | 超过千位使用千分位分隔 |
| 空值 | `--` |

### 5.2 百分比

【新增】统一建议：

| 场景 | 展示规则 |
|------|------|
| 整数占比 | `12%` |
| 常规百分比 | 默认保留 1 位小数，如 `12.3%` |
| 高精度场景 | 仅在业务明确要求时保留 2 位小数 |
| 空值 | `--` |

【删除建议】不建议：

- 同页面同时出现 `12%`、`12.0%`、`12.00%`

### 5.3 风险分 / 评分

【新增】统一建议：

1. 分值默认右对齐。
2. 如带区间含义，应同时定义颜色映射和文案区间。
3. 不允许只显示颜色，不显示数值或等级说明。

## 6. 时间展示规范

### 6.1 通用时间格式

【新增】建议优先统一为：

| 场景 | 推荐格式 |
|------|------|
| 日期 | `YYYY-MM-DD` |
| 日期时间 | `YYYY-MM-DD HH:mm:ss` |
| 仅时间 | `HH:mm:ss` |
| 月维度统计 | `YYYY-MM` |
| 空值 | `--` |

### 6.2 相对时间

【新增】统一建议：

1. 表格和详情页优先显示绝对时间。
2. 如需辅助展示，可在 tooltip 或副文案补充相对时间，例如“5 分钟前”。
3. 不建议只显示相对时间。

### 6.3 时长展示

【新增】统一建议：

| 场景 | 展示规则 |
|------|------|
| 秒级 | `32 秒` |
| 分钟级 | `5 分 32 秒` |
| 小时级 | `2 小时 15 分` |
| 空值 | `--` |

## 7. IP、主机名、标识类字段规范

### 7.1 主机名

【新增】统一建议：

1. 主机名作为主标识时，优先展示在文本首位。
2. 超长时单行省略并支持 tooltip。
3. 如主机名和 IP 同时存在，优先主机名在上、IP 在下，或主机名在前、IP 在后，页面内统一。

### 7.2 IP 地址

【新增】统一建议：

1. IP 保持原始格式，不做非必要缩写。
2. 支持复制。
3. 空值统一显示 `--`。

### 7.3 ID / 编码类字段

【新增】统一建议：

1. 默认次级展示，不应比业务名称更抢眼。
2. 建议支持复制。
3. 超长时单行省略。

## 8. 标签 / 徽标展示规范

### 8.1 标签展示规则

【新增】统一建议：

1. 普通标签用于分类、来源、能力标识。
2. 状态标签必须使用 `StatusBadge`，不与普通标签混用。
3. 标签超过容器宽度时，优先折叠或省略，不要撑破布局。

### 8.2 标签数量规则

【新增】统一建议：

1. 表格单元格中标签超过 2 个时，可采用 `+N` 收敛。
2. 详情页中可完整展开，但需控制换行节奏。

【删除建议】不建议：

- 标签数量多时无限横向撑开
- 把状态和分类标签做成完全一样的视觉，无法区分

## 9. KPI / 指标卡展示规范

### 9.1 指标卡基础规则

【新增】统一建议：

| 项目 | 规范 |
|------|------|
| 标题 | 使用一级或二级文本色 |
| 数值 | 使用数字字体 token |
| 单位 | 次于数值，不应抢主视觉 |
| 趋势 | 上升/下降需有颜色和方向双重提示 |
| 空值 | `--` |

### 9.2 趋势规则

【新增】统一建议：

1. 趋势上升不一定永远代表正向，需按业务定义颜色。
2. 如果颜色含义有歧义，必须补图标或文字说明。
3. 趋势值和主指标之间要有明确主次。

## 10. 给 IDE / AI 的使用说明

【新增】把本规范交给 IDE 时，建议附加以下要求：

```md
1. 所有数据字段都必须先判断展示类型，再决定格式。
2. 表格、图表、详情区中的同名字段必须使用同一种展示格式。
3. 空值统一为 `--`，状态统一走 `StatusBadge`。
4. 主机名、任务名、模板名、策略名等长文本默认单行省略并支持 tooltip。
5. 时间、时长、百分比、数值格式必须在页面中保持一致。
6. 如果字段格式在设计稿和规范中都未定义，先输出“字段展示建议”，不要直接拍脑袋实现。
```
