# 间距与布局设计规范 (Spacing & Layout)

> [!IMPORTANT]
> **规范工程化：** 本文档负责布局逻辑说明。核心尺寸和间距数值已迁移至 [variables/_spacing.scss](file:///Users/dd/Documents/王建宇的 IDE 工作空间/qaxd-ds/resource/tokens/variables/_spacing.scss)。


## Ⅰ. 布局规范 (Layout Specifications)

布局规范定义了界面的核心骨架，决定了信息的展示密度与适配逻辑。

### 1. 布局核心准则
- **导航定位**：由 `header-height` (56px) 和 `sidebar-width` (216px) 锁定核心框架。
- **响应式策略**：侧栏固定，内容区基于 24 栅格动态适配；超宽屏内容区建议居中或锁定最大宽度。
- **对齐要求**：所有区块边界必须对齐栅格列，Gutter (16px) 严禁压缩。

### 2. 布局模式 (Layout Modes)
- **上下布局 (Top-Bottom Layout)**：结构简单，符合浏览习惯，适用于单一功能模块。
- **固定布局 (Fixed Layout)**：无论屏幕多大，内容展示区宽度一致，视觉聚焦，适合展示类页面。
- **左右布局 (Left-Right Layout)**：侧边栏承载力强，适合多级菜单导航，是中后台最常用模式。
- **混合布局 (Hybrid Layout)**：顶部展示业务维度，左侧展示子菜单或功能树，适合复杂架构。

### 3. 布局变量与参数 (Layout Tokens & Params)

#### 核心尺寸 Token
| Token 名 | 声明 | 适用场景示例 |
| :--- | :--- | :--- |
| `--layout-header-height` | 顶栏高度 | 页面固定高度的全局页头 |
| `--layout-sidebar-width` | 侧边导航宽度 | 侧边栏展开时的标准宽度 |
| `--layout-gutter-width` | 布局间距 | 内容展示区域与导航、区块之间的间距 |

#### 栅格与画板参数
| 属性 | 规范说明 |
| :--- | :--- |
| **标准画板** | UI 设计与评审的基准宽度。 |
| **栅格列数** | 采用主流的 24 栅格体系。 |
| **网格基数** | 所有尺寸决策的最小模度，建议 8x 步进。 |

#### 分辨率断点 (Breakpoints)
| 断点级别 | 适配描述 |
| :--- | :--- |
| **SM** | 极限小屏幕适配点。 |
| **MD** | 主流笔记本电脑分辨率。 |
| **LG (Default)** | 基准设计分辨率。 |
| **XL** | 桌面大显示器/高分辨率屏。 |

## Ⅱ. 间距规范 (Spacing Specifications)

间距系统使用「8像素基本单元」原则。任何需要自定义的长、宽、Margin 和 Padding 都应当引用规范 Token，其背后数值基于 8 的倍数。

### 1. 间距使用建议
- **亲密性原则**：信息关联度越高，使用的间距 Token 应越小（如图标与文字）。
- **空间一致性**：同一层级的容器在横向和纵向上建议使用相同的间距 Token。
- **特殊例外**：在处理居中对齐或精密绘图时，可不受 8px 限制，但应尽量对齐 4px 辅助步长。

### 2. 变量定义 (Token Definitions)
| Token 名 | 声明 | 适用场景示例 |
| :--- | :--- | :--- |
| `--spacing-compact` | 间距-紧凑 | 图标与文字之间、小标签内部间距 |
| `--spacing-standard` | 间距-偏紧凑 | 按钮/输入框等基础控件之间的间隙 |
| `--spacing-loose` | 间距-默认 | 区块内部元素组织、标准内容填充 |
| `--spacing-wide` | 间距-宽松 | 页面大模块/卡片之间的间距 |
| `--spacing-vast` | 间距-超宽松 | 页面核心版块、页头与内容区之间 |
