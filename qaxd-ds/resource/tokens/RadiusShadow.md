# 圆角与阴影设计规范 (Radius & Shadows)

> [!IMPORTANT]
> **规范工程化：** 圆角倍率和阴影层级数值已迁移至 [variables/_radius-shadow.scss](file:///Users/dd/Documents/王建宇的 IDE 工作空间/qaxd-ds/resource/tokens/variables/_radius-shadow.scss)。开发建议直接使用语义化 Token。


## 使用建议

1. **圆角嵌套法则**：内层元素的圆角应小于或等于外层容器的圆角，以符合视觉上的缩进比例。
2. **光源一致性**：全系统应维持单一光源方向。本规范默认为 **轴向向下阴影 (-down)**，若在侧边栏或底部工具条使用，其模糊度（Blur）和扩展值（Spread）应保持一致。
3. **层级逻辑**：阴影的级别应直接反映组件在 Z 轴上的物理高度。如 Dialog (L4) 必须高于 Hover 卡片 (L2)，以确保覆盖关系明确。
4. **品牌一致性**：当前的圆角设置（2px - 8px）倾向于硬朗、效率型的企业级风格，配合柔和的弥散投影，旨在营造轻盈、专业的质感。

## 圆角 (Corner Radius)

圆角定义了元素的外部轮廓，能够增加界面的结构感。

| Token 名 | 声明 | 适用场景示例 |
| :--- | :--- | :--- |
| `--radius-content` | 基础组件超小圆角 | 适用于：复选框、小标签、标记等。 |
| `--radius-wrapper` | 基础组件通用圆角 | 适用于：按钮、输入框、选择器等标准交互控件。 |
| `--radius-container` | 组件内部层级嵌套圆角 | 适用于：组件内部的嵌套模块、细分卡片等。 |
| `--radius-outer` | 最外层圆角 | 适用于：卡片、大型对话框（Dialog）的最外层轮廓。 |

## 阴影 (Shadows)

阴影通过视觉深度区分页面层级，我们将页面层级分为五个等级（L0 - L4）。

| Token 名 | 声明 | 适用场景示例 |
| :--- | :--- | :--- |
| `--shadow-none` | 无投影 (L0) | 基础平面背景 |
| `--shadow-l1` | 第一层级阴影 (L1) | 顶部导航、按钮、基础卡片 |
| `--shadow-l2` | 第二层级阴影 (L2) | Hover 状态的卡片、拖拽元素的抬升 |
| `--shadow-l3` | 第三层级阴影 (L3) | 下拉菜单 (Dropdown)、气泡确认框 (Popover)、提示 (Tooltip) |
| `--shadow-l4` | 第四层级阴影 (L4) | 对话框 (Dialog)、全局通知、抽屉 (Drawer) |

> [!NOTE]
> 以上默认值为浅色模式 (Light)。在深色模式 (Dark) 下，阴影颜色通常使用 `rgba(var(--gray-0), 0.4~0.5)`，以确保在暗背景上有足够的对比度。
