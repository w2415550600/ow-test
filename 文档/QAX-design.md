# 奇安信设计系统 (QAX Design System)

> 分类：企业安全 / B2B 协作平台
> 网络安全运营。浅色模式为默认，高对比棱角界面，苹方字体，数据密集型指挥中心。

## 1. 视觉主题与氛围

奇安信的界面语言是一套为安全分析师与运维人员量身打造的精密运营系统，服务于高压威胁场景下的长时间操作。视觉基调为持续专注而设计：深邃的暗色画布吸收视觉疲劳，高对比前景元素穿透信息密度，棱角分明的几何语言强化结构权威感。界面的使命是成为指挥中心——压力之下沉稳冷静，效率至上，始终掌控全局。

在已分析的三类页面中，系统以两种统一但分化的模式运行。**深色运营模式**（仪表盘、威胁监控、安全态势）以午夜深色画布（`#16181C`）为底，叠加半透明层级卡片与发光强调信号——这是安全分析师长时间操作的默认环境。**浅色管理模式**（资产管理、配置、协作流程）以洁净的白色平面承载，搭配克制的灰色边框与紧凑的实用控件——适用于日常管理和跨团队协同。两种模式共享完全相同的字体、间距节奏和组件基因，仅通过表面极性和对比方向进行区分。

字体排版是信息层次的骨干。苹方-简（PingFang SC）以精确校准的七级字号阶梯承载整个界面——从 32px 页面标题到 12px 正文和微标签。数值数据获得特殊待遇：DIN Alternate 以机械精度渲染仪表盘关键指标，`tabular-nums` 确保表格和图表中的纵向对齐。字重阶梯刻意收敛——400 承载信息负荷，700 标记结构强调——避免数据密集环境中的视觉噪声。

**核心特征：**
- 双极表面体系：深色运营画布（`#0c0f20`、`#16181C`）与浅色管理平面（`#FFFFFF`、`#F3F3F4`）
- 单一蓝色强调家族，统管操作、导航和安全状态语义（浅色 `#105CF4` / 深色 `#3676F6`）
- 一套系统双模式：深色运营指挥中心与浅色管理实用平面
- 高信息密度为默认状态；留白是功能性的，绝非装饰
- 棱角几何语言，极简圆角（2px–8px），强化精确与权威感
- 紧凑字体指标（苹方 SC，12px–32px 范围），优化纵向数据扫描
- 四级圆角体系（2→4→6→8px），映射内容→包裹→容器→外层的嵌套层级
- 深度通过透明度步进和填充不透明度层级实现，而非厚重阴影堆叠
- 安全域专属色彩词汇：威胁等级、攻击状态、任务状态为一级调色板成员

## 2. 色彩体系与角色

> **唯一事实源 (SSOT)：** `resource/tokens/variables/_colors.scss`。以下所有色值均为浅色模式默认值；深色模式通过 `[data-theme='dark']` 自动映射。

### 主色
- **品牌蓝** (`#105CF4` / 深色：`#3676F6`)：主要操作填充、激活导航、焦点信号和安全状态强调。整个色彩体系的锚点。
- **近黑墨色** (`#1E2127` / 深色：`#F6F6F7`)：浅色表面上的主要文字；深色表面上反转为高亮度文字。
- **沉降灰** (`#F3F3F4` / 深色：`#16181C`)：次级背景，用于内容凹槽、表头和下沉容器。

### 辅助与强调
- **悬停强调** (`#3A79F6` / 深色：`#6194F8`)：品牌蓝的悬停态提亮，用于交互反馈。
- **激活强调** (`#0A4ACA` / 深色：`#3A79F6`)：品牌蓝的激活/按下态加深。
- **强调填充** (`#E8F0FF` / 深色：`#011A4D`)：带色调的背景填充，用于强调上下文容器和选中行高亮。
- **链接蓝** (`#1082F4` / 深色：`#3696F6`)：行内链接色，与操作蓝区分，优化密集数据表中的可点击文字。

### 表面与背景

背景色按层级从抬升到下沉排列，层级越低越接近系统底色：

- **抬升表面** (`#FFFFFF` / 深色：`#373C47`)：一级背景色——用于 Dropdown Menu、Popover、Tooltip 等浮层。
- **覆盖表面** (`#FFFFFF` / 深色：`#292D35`)：二级背景色——用于 Dialog、Notification、Message 等弹窗。
- **容器表面** (`#FFFFFF` / 深色：`#20242A`)：三级背景色——用于容器背景色，如卡片、布局块等。
- **沉降底色** (`#F3F3F4` / 深色：`#16181C`)：四级背景色——用于系统底色。
- **强调背景** (`#F8F8F9` / 深色：`rgba(246,246,247,0.06)`)：同层级内容的强调背景，禁止乱用。
- **遮罩** (`rgba(30,33,39,0.5)` / 深色：`rgba(22,24,28,0.5)`)：弹窗和抽屉的半透明遮罩层。

### 中性色与文字
- **次要文字** (`#292D35` / 深色：`#DDDFE3`)：正文和标准内容文字。
- **辅助文字** (`#6D7585` / 深色：`#A6ABB4`)：帮助描述、元数据和弱化标签。
- **占位文字** (`rgba(168,173,182,0.65)` / 深色：`rgba(246,246,247,0.35)`)：占位符和禁用态内容。
- **主要边框** (`#C8CBD1` / 深色：`rgba(246,246,247,0.2)`)：控件描边和输入框边框。
- **次要边框** (`#ECEDEF` / 深色：`rgba(246,246,247,0.1)`)：容器分割线和卡片分隔。
- **悬停填充** (`#ECEDEF` / 深色：`rgba(246,246,247,0.15)`)：行悬停和交互元素背景填充。

### 语义与状态
- **成功** (`#00B82B` / 深色：`#28C64D`)：确认、完成、安全状态和安全通过指示。
- **警示** (`#F48210` / 深色：`#F69636`)：注意、待处理和中危告警状态。
- **危险** (`#F42738` / 深色：`#F74D5B`)：严重告警、破坏性操作和高危威胁指示。
- **信息** (`#1082F4` / 深色：`#3696F6`)：中性信息通知和客观状态信号。

### 安全域状态色
- **威胁严重** (`#A00D19` / 深色：`#A01420`)：需要立即响应的紧迫威胁。
- **威胁高危** (`#F42738` / 深色：`#F74D5B`)：高严重性安全发现。
- **威胁中危** (`#F48210` / 深色：`#F69636`)：中等风险指标。
- **威胁低危** (`#F4CB00` / 深色：`#F6D531`)：低严重性观察。
- **威胁安全** (`#00B82B` / 深色：`#28C64D`)：已验证安全状态。
- **威胁未知** (`#A8ADB6` / 深色：`#6F7787`)：无法分类或待分析状态。

### 数据可视化色板
- 18色感知均匀分类色板，专用于图表和数据可视化。严禁在 UI 控件或交互组件中使用。

### 渐变系统
- 渐变使用极为克制。深色模式卡片使用默认颜色（容器表面 `#20242A` 填充 + 次要边框 `rgba(246,246,247,0.1)` 描边）而非自定义渐变玻璃效果。浅色模式同样依赖纯色表面和边框约束。
- 侧栏底部可使用径向渐变光晕（`radial-gradient(circle, rgba(61,83,247,0.08) 0%, transparent 70%)`）营造氛围深度，但仅限于导航上下文的装饰性背景，不用于卡片或交互组件。

## 3. 字体排版规则

### 字体家族
- **主字体家族：** `PingFang SC`，回退 `-apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, "Helvetica Neue", Arial, "Noto Sans", sans-serif`
- **数值显示：** `DIN Alternate`，回退 `"Helvetica Neue", sans-serif`——专用于仪表盘关键指标值、大格式计数器和数据监控数值。
- **使用分工：** PingFang SC 承载所有界面文字，包括标题、标签、正文和微文本。DIN Alternate 仅用于需要机械精度和垂直比例的独立数值显示。

### 层级体系
| 角色 | 字号 | 字重 | 行高 | Token | 备注 |
|------|------|------|------|-------|------|
| 一级标题 | 32px | 700 | 40px | `--font-size-heading-1` | 页面级标题、顶级区段名称 |
| 二级标题 | 28px | 700 | 36px | `--font-size-heading-2` | 模块标题、弹窗标题 |
| 三级标题 | 24px | 700 | 32px | `--font-size-heading-3` | 子模块标题、卡片标题 |
| 四级标题 | 20px | 700 | 28px | `--font-size-heading-4` | 容器标题、区段副标题 |
| 五级标题 | 16px | 700 | 24px | `--font-size-heading-5` | 小标题、侧栏区段名 |
| 六级标题 | 14px | 700 | 22px | `--font-size-heading-6` | 侧栏条目、引导标签 |
| 正文 | 12px | 400 | 20px | `--font-size-body` | 标准正文、表格内容、表单标签 |
| 关键指标数值 | 24px | 500 | — | DIN Alternate | 仪表盘指标值、计数器显示 |
| 表格表头 | 12px | 600 | — | 正文 Token | 数据表格列标题 |
| 微标签 | 12px | 400–600 | — | 正文 Token | 状态徽章、标签、翻页、附注 |

### 原则
- **以字号和字重构建层次：** 七级字号阶梯配合二字重体系（400/700）创造清晰的视觉分层，无需引入增加噪声的中间字重。
- **密度中的可读性：** 正文 12px 搭配 20px 行高，在安全运营典型的紧凑数据表和配置表单中保持可读性。
- **数值对齐：** 所有表格数据、计数器和仪表盘指标必须声明 `font-variant-numeric: tabular-nums`，确保不同宽度数字的纵向对齐。
- **克制的字重阶梯：** 200（细体）仅出现在装饰或弱化上下文；400 承载信息负荷；700 标记结构强调。不使用 500/600 字重以避免视觉模糊。

### 字体替代说明
- 最佳免费替代方案：`Inter` 用于正文密集的实现，`Noto Sans SC` 用于 CJK 覆盖。
- 替代 PingFang SC 时，正文字号行高增加 +2px 以补偿更紧凑的 CJK 度量。
- DIN Alternate 替代方案：`Roboto Mono` 或 `JetBrains Mono` 用于数值显示，但字间距应减少 -0.5px 以近似 DIN 的紧凑比例。

## 4. 组件样式规范

### 按钮
- **主要填充按钮：** 品牌蓝（`#105CF4` / 深色 `#3676F6`）背景，白色（`#FFFFFF`）文字，4px 圆角。用于核心操作点（创建任务、确认、执行扫描）。
- **默认描边按钮：** 白色（`#FFFFFF` / 深色 `#20242A`）填充 + 主要边框（`#C8CBD1` / 深色 `rgba(246,246,247,0.2)`）边框，近黑墨色（`#1E2127` / 深色 `#F6F6F7`）文字，4px 圆角。常规次要操作。
- **文字按钮：** 无背景无边框，近黑墨色（`#1E2127` / 深色 `#F6F6F7`）文字。低优先级行内操作，常见于表格行内或列表。
- **虚线按钮：** 次要边框（`#ECEDEF` / 深色 `rgba(246,246,247,0.1)`）虚线边框，透明填充。引导添加、导入等辅助性操作。
- **幽灵按钮：** 透明背景 + 品牌蓝（`#105CF4` / 深色 `#3676F6`）边框和文字。用于深色或彩色背景上的操作。
- **危险按钮：** 危险红（`#F42738` / 深色 `#F74D5B`）填充或文字变体，用于破坏性不可逆操作（删除、断开、强制终止）。
- **尺寸阶梯：** 中号（40px 高度，16px 内边距），小号（32px，12px 内边距），迷你（24px，8px 内边距）。中号和小号使用 14px 字号，迷你使用 12px。
- **按钮组：** 零间距拼接，`margin-left: -1px` 边框重叠；首按钮仅保留左侧圆角（`4px 0 0 4px`），中间按钮圆角为 0，末尾按钮仅保留右侧圆角（`0 4px 4px 0`）。

### 卡片与容器
- **深色运营卡片：** 容器表面（`#20242A`）填充 + 次要边框（`rgba(246,246,247,0.1)`）描边 + 8px 圆角。悬停态边框切换为品牌蓝半透明（`rgba(60,126,255,0.3)`）并附带蓝色调阴影。
- **浅色管理卡片：** 纯白 `#FFFFFF` 填充 + 次要边框（`#ECEDEF`）1px 边框 + 8px 圆角。行悬停使用悬停填充（`#ECEDEF` / 深色 `rgba(246,246,247,0.15)`）。
- **关键指标卡片（KPI）：** 紧凑 88px 高度容器；深色模式使用容器表面（`#20242A`）填充 + 次要边框（`rgba(246,246,247,0.1)`）描边（与深色运营卡片一致），56px 圆形图标指示器（蓝/青/紫/红变体），DIN Alternate 24px 数值；浅色模式采用白底 + 次要边框（`#ECEDEF`）边框 + 阴影 + 48px 圆形图标。
- **模板/功能卡片：** 164px 高度纵向卡片，正文/底栏分割；底栏用顶部分割线隔开，配双操作链接。激活态以强调边框高亮表示。

### 输入与表单
- **标准输入框：** 容器表面（`#FFFFFF` / 深色 `#20242A`）填充，主要边框（`#C8CBD1` / 深色 `rgba(246,246,247,0.2)`）边框，4px 圆角，32px 默认高度。焦点态边框过渡为强调蓝焦点色（`#6495F8` / 深色 `#6495F8`）并附带微光。
- **尺寸层级：** 大号（40px），默认（32px），小号（24px）。表单容器向下传播 `size` 属性至所有子输入组件——同一表单中禁止混用尺寸。
- **标签对齐：** 右对齐标签（默认首选，阅读链最短）；左对齐用于标签字数差异大的场景；顶部对齐用于紧凑型移动端或强引导流程。
- **选择器下拉：** 浮层背景使用抬升表面（`#FFFFFF` / 深色 `#373C47`），选中项以品牌蓝（`#105CF4` / 深色 `#3676F6`）文字高亮。多选标签高度比外层 Input 低 6–8px。
- **校验：** 错误态使用危险红（`#F42738` / 深色 `#F74D5B`）边框 + 行内错误文字；在失去焦点（blur）时触发反馈。

### 导航
- **侧栏导航（NavMenu）：** 固定 216px 宽度（收起 64px），56px Logo 区域，40px 菜单项高度。激活项：品牌蓝（`#105CF4` / 深色 `#3676F6`）填充 + 白色文字/图标。悬停：悬停填充（`#ECEDEF` / 深色 `rgba(246,246,247,0.15)`）+ 4px 圆角。多级：嵌套子菜单使用沉降底色（`#F3F3F4` / 深色 `#16181C`）区分层级深度。
- **面包屑导航：** 紧凑 24px 高度顶栏，辅助文字色图标 + 次要文字色标签。
- **表格表头导航：** 可排序列附带行内排序指示器；区段标题附带操作链接或紧凑强调边框按钮组。

### 图标与视觉语言
- **图标优先的 UI：** SVG 线性图标（标准 16px，导航中 14px）作为主要视觉语言——摄影图片在安全运营界面中居于次要地位。
- **几何 Logo 标记：** 奇安信品牌标记采用四象限棱角构图，品牌蓝色（`#3d53f7`/`#5fafff`），强调结构与精确。
- **状态点语言：** 8px 圆形指示器（`status-dot`）配合语义色表达任务状态——待处理（橙色）、运行中（蓝色）、已完成（绿色）、失败（红色）、已取消（灰色）。
- **图标系统：** `@store.bizicon/skyeye-qgpt`（270+ 图标，Vue 组件 `i-` 前缀），四种渲染风格（outline/filled/twoTone/multiColor），包含安全域专属分类：攻击路径、威胁行为体、运营流程。

### 其他特色组件
- **进度条：** 72px×6px 轨道，浅色模式使用次要边框（`#ECEDEF`）背景、品牌蓝填充；深色模式使用 `rgba(246,246,247,0.2)` 背景。附带百分比文字标签。
- **主机统计条：** 多段横向条（168px×6px，1px 圆角），以绿/红/橙分布展示安全扫描结果。
- **开关切换：** 28px×16px 胶囊体 + 12px 圆形滑块；关闭态使用 `rgba(246,246,247,0.2)` 轨道，开启态使用品牌蓝（`#105CF4` / 深色 `#3676F6`）填充。
- **翻页器：** 32px×32px 方形页码按钮，4px 圆角 + 1px 边框；激活页使用强调填充；包含省略号折叠和前往输入框。
- **状态徽章：** 行内徽章 = 8px 状态点 + 文字标签；标签式徽章 = 带色调背景（如 `rgba(60,126,255,0.1)` 蓝色标签，`rgba(40,198,77,0.1)` 绿色标签）。
- **安全评分环：** 88px CSS 圆环，配合 SVG stroke-dasharray 实现进度，中心显示 DIN Alternate 评分数值，底部为等级标签。

## 5. 布局原则

### 间距体系
- 基本单位为 `8px`，通过五个命名间距 Token 强制执行。
- Token 阶梯：`--spacing-compact`（4px）、`--spacing-standard`（8px）、`--spacing-loose`（16px）、`--spacing-wide`（24px）、`--spacing-vast`（32px）。
- 允许 4px 辅助步长用于居中和精确对齐，但所有结构性间距必须对齐至 8px 倍数。
- 亲密性原则：关联元素使用较小 Token（图标与文字：4–8px）；无关联模块使用较大 Token（卡片之间：16–24px）。

### 栅格与容器
- **24列栅格系统**，16px 沟槽宽度，严禁压缩。
- **布局锚点常量：** `--layout-header-height`（56px）和 `--layout-sidebar-width`（216px）锁定应用框架。
- **四种布局模式：** 上下布局（简单单模块）、固定布局（居中内容限最大宽度）、左右布局（侧栏 + 内容，B2B 最常用）、混合布局（顶栏 + 侧栏，复杂架构）。
- 标准设计画布：1440px 宽度为 UI 设计和评审基准。

### 页面布局模式 ⭐

> 以下模式从三个 demo 模板中提取，是所有页面必须遵循的刚性规则。

#### 内容区与画布间距
- 主内容区四周**必须保持 16px 间距**（布局沟槽），包括上、右、下、左四个方向，与画布边缘（视口或侧栏边界）之间不可塌缩为零。
- 通过 `padding: 16px` 在主内容容器上实现。
- 各模块之间的间距统一使用 `gap: 16px`，确保一致节奏。

#### 表格区段头部布局（核心模式）
- **两行结构：**
  - **第一行：** 仅区段标题（14px，字重 700，次要文字色 `#292D35` / 深色 `#DDDFE3`）。
  - **第二行：** 主要操作按钮居**左侧** + 筛选控件居**右侧**，两者在同一水平线上（`align-items: center`）。两行间距 16px。
- **左侧（第二行）：** 主要操作按钮（创建、添加、执行）**必须放在标题正下方、居左侧**，绝不能出现在右上角。这建立了清晰的视觉阅读顺序：标题 → 操作 → 数据。
- **右侧（第二行）：** 筛选控件（下拉选择器、搜索输入框、日期选择器）通过 `margin-left: auto` 右对齐，占据按钮组对面的水平空间。
- **结构实现：** 区段头部使用 `flex-direction: column`，工具栏行使用 `display: flex; align-items: center;`。工具栏左侧组包含按钮，右侧组（`margin-left: auto`）包含筛选控件。窄视口下元素自动换行。

#### 表格容器内边距
- 表格区段使用 `flex: 1` 填充 KPI 卡片和顶栏之后的剩余纵向空间。
- 表格主体（`table-wrapper`）使用 `overflow: auto` 配合粘性表头（`position: sticky; top: 0`）实现内部纵向滚动。
- **表格内边距：** 表格内容与背景容器之间**必须保持 16px** 水平内边距——通过 `padding: 0 16px` 实现。确保表格内容绝不触及卡片边界。
- **区段头部分隔线：** 区段头部与表格主体之间的分隔线**左右各缩进 16px**——通过 `::after` 伪元素配合 `left: 16px; right: 16px` 实现，而非全宽 `border-bottom`。这使得分隔线在视觉上与表格内容边缘对齐。
- 表格最小宽度 900px；视口更窄时激活横向滚动。

#### 翻页器定位
- 翻页器**必须在表格底部、居右侧展示**（`justify-content: flex-end`）。
- 翻页器与表格内容之间用顶部分割线（次要边框色 `#ECEDEF` / 深色 `rgba(246,246,247,0.1)`）隔开。
- 翻页器内边距：`8px 16px`。

#### KPI 指标卡网格
- 浅色管理模式：4列 CSS Grid（`grid-template-columns: repeat(4, 1fr)`），16px 间距。
- 深色运营模式：3列 CSS Grid（`grid-template-columns: repeat(3, 1fr)`），16px 间距。
- 卡片流式填充可用宽度；无固定像素宽度。
- KPI 行使用 `flex-shrink: 0` 保持固定高度，不参与纵向弹性分配。

#### 资产详情页双栏布局
- 基本信息与安全态势采用 1:1 双栏 Grid（`grid-template-columns: 1fr 1fr`），16px 间距。
- 窄视口（≤1280px）降级为单栏堆叠。

### 留白哲学
- **功能性密度：** 留白用于分离信息组，而非创造编辑式呼吸空间。安全运营界面优先保障信息密度。
- **一致的空间节奏：** 同层级容器在横向和纵向上使用相同的间距 Token。
- **对比主导的分离：** 深色模式表面依赖填充不透明度步进和渐变区分，而非显式边框。浅色模式使用边框约束。

### 圆角阶梯
- **2px**（`--radius-content`）：复选框、微标签、行内状态点——极简曲率，精确感。
- **4px**（`--radius-wrapper`）：按钮、输入框、选择器、导航项——标准交互控件几何。
- **6px**（`--radius-container`）：内层嵌套模块、大容器内的子卡片——中间嵌套层。
- **8px**（`--radius-outer`）：顶级卡片、弹窗、大型容器——最外层壳体圆角。
- **嵌套法则：** 内层圆角必须 ≤ 外层圆角；每级嵌套减少一档（8→6→4→2）。

## 6. 层级与深度

| 层级 | 处理方式 | 用途 |
|------|---------|------|
| L0 | 平坦基础表面（浅色：`#FFFFFF`/`#F3F3F4`；深色：`#16181C`/`#20242A`） | 页面背景、下沉内容凹槽 |
| L1 | 微弱阴影（`0 1px 2px 0 rgba(30,33,39,0.1)`） | 顶部导航栏、默认按钮、基础卡片 |
| L2 | 中等阴影（`0 4px 8px 0 rgba(30,33,39,0.1)`） | 悬停抬升卡片、拖拽元素 |
| L3 | 显著阴影（`0 8px 16px 4px rgba(30,33,39,0.1)`） | 下拉菜单、气泡确认框、提示 |
| L4 | 深层阴影（`0 12px 24px 8px rgba(30,33,39,0.1)`） | 弹窗、全局通知、抽屉 |
| 无障碍 | 强调蓝焦点环（`#6495F8`） | 键盘焦点和选中强调 |

深度刻意收敛且系统化。奇安信在深色模式中偏好填充不透明度分层，在浅色模式中偏好边框约束，而非厚重阴影累积。阴影层级直接映射 Z 轴物理高度——L4 弹窗必须在视觉上压过 L2 悬停卡片。

### 装饰深度
- 深色模式通过透明度步进创造深度：`rgba(246,246,247,0.04)` → `0.06` → `0.08` → `0.1` 不透明度边框和渐变填充产生微妙的表面区分，无需合成阴影效果。
- 径向渐变强调（如 `radial-gradient(circle, rgba(61,83,247,0.08) 0%, transparent 70%)`）在侧栏和导航上下文中提供氛围深度提示。
- 浅色模式主要通过沉降底色（`#F3F3F4` / 深色 `#16181C`）表面步进和次要边框（`#ECEDEF` / 深色 `rgba(246,246,247,0.1)`）约束实现深度。
- 卡片悬停态引入蓝色调边框过渡（`rgba(60,126,255,0.3)`）配合微弱蓝色辉光阴影，提供交互深度反馈。

## 7. 设计守则

### 应做
- **当用户提示词未明确指定深色或浅色模式时，默认必须使用浅色模式进行设计。** 只有在用户显式要求深色模式时，才切换为深色运营表面。
- 使用语义 Token 系统（`--color-accent`、`--color-text-primary` 等）作为代码中的唯一色彩引用；设计文档中必须同时标注具体色值以确保自包含。
- 为所有表格数据、计数器和仪表盘指标启用 `font-variant-numeric: tabular-nums`。
- 遵循圆角嵌套法则：内层元素使用比容器更小的圆角（8→6→4→2）。
- 维持 8px 间距网格；4px 辅助步长仅用于居中和精细对齐。
- 使用安全域状态色（威胁等级、攻击结果、任务状态）于其指定的业务上下文。
- 向下传播表单 `size` 属性至子组件，确保数据录入流的视觉一致性。
- 使用 DIN Alternate 渲染独立仪表盘数值，最大化数据扫描效率。
- 以表面极性区分深色运营面和浅色管理面，同时保持所有其他 Token 共享。
- 表格区段头部遵循两行结构：标题在上，按钮居左 + 筛选器居右在下。
- 翻页器始终在表格底部右侧展示。
- 表格内容与容器之间保持 16px 内边距。

### 不应做
- 不在组件代码中直接使用基础色板色值（如 `$primitive-brand-3`）；始终引用语义 Token。
- 不在同一表单或数据录入组中混用控件尺寸（40px/32px/24px 不得共存）。
- 不引入超过 8px 最大圆角的圆形或胶囊几何；本系统以棱角为设计基调。
- 不将数据可视化色板颜色（`--color-data-*`）用于 UI 控件、按钮或交互组件。
- 不在卡片或交互控件上使用自定义渐变玻璃效果；深色运营卡片使用默认 Token 颜色（容器表面 `#20242A` 填充 + 次要边框 `rgba(246,246,247,0.1)` 描边）。渐变仅限侧栏导航的装饰性径向光晕。
- 不在任何响应式条件下压缩 24 列栅格的 16px 沟槽宽度。
- 不以任意值覆盖阴影 Token；阴影层级必须反映真实的 Z 轴层级。
- 不将深色和浅色模式视为分离的设计系统；它们共享相同的字体、间距和组件基因。
- 不在深色模式中使用阴影作为主要区分手段；使用透明度步进和填充不透明度替代。
- 不将操作按钮放在区段标题的右上角；必须放在标题正下方左侧。
- 不让翻页器居中或居左展示；必须居右。
- 不让表格内容贴紧容器边缘；必须保持 16px 内边距。

## 8. 响应式行为

### 流式布局基础
- 所有页面布局必须**完全响应式**，以 `100vw × 100vh` 为视口基准，绝不使用固定像素尺寸（如 `1440px × 900px`）。
- 侧栏宽度固定（展开 216px，收起 64px）；主内容区通过 `flex: 1` 配合 `min-width: 0` 填充剩余宽度，防止溢出。
- 所有区段之间的纵向间距使用 `gap: 16px`，确保适应内容高度的一致节奏。
- 表格区段使用 `flex: 1` 吸收所有剩余纵向空间；KPI 卡片和顶栏使用 `flex-shrink: 0` 保持固定高度。
- 内容区使用 `overflow-y: auto` 处理纵向滚动；表格主体使用 `overflow: auto` 配合粘性表头实现内部滚动。
- 最小视口宽度：`1024px`（通过 `body` 的 `min-width` 设定）。低于此阈值允许横向滚动，而非进一步压缩布局。

### 断点
| 名称 | 宽度 | 关键变化 |
|------|------|---------|
| SM（小屏） | ≤1280px | 侧栏收起为 64px 仅图标模式；KPI 网格转为 2×2 或 1 列；筛选输入框压缩 |
| MD（中屏） | 1281–1366px | 完整侧栏；KPI 网格保持 4 列但内边距缩减；筛选输入框变窄 |
| LG（默认） | 1367–1440px | 设计基准；完整布局配合标准间距 Token |
| XL（大屏） | ≥1441px | 扩展内容区；所有组件完整内边距；舒适间距 |

### 触控目标
- 所有交互控件保持最小 32px 点击区域（小号按钮高度）。
- 导航菜单项使用 40px 高度 + 8px 水平内边距，确保舒适触达。
- 翻页按钮 32px×32px，2px 间距分离。
- 开关切换使用 28px×16px 视觉区域，隐含更大的触控目标。

### 折叠策略
- 侧栏从 216px（展开带文字标签）折叠为 64px（仅图标模式），在 SM 断点或用户切换时触发。
- 内容区通过 24 列栅格适配，固定 16px 沟槽；列数按比例减少。
- KPI 卡片行在 LG/XL 保持 4 列网格（深色 3 列），SM/MD 可堆叠为 2×2 或单列。
- 表格区段保持列可读性；列超出视口宽度时激活横向滚动。
- 表单布局从右对齐标签（桌面端）切换为顶部对齐标签（紧凑视口）。

### 图像行为
- SVG 图标在断点间等比缩放，无损质量。
- 仪表盘图表和数据可视化保持宽高比，随容器宽度响应。
- Logo 标记在所有断点保持 32px 显示尺寸；收起侧栏模式下文字标题隐藏。
- 状态点和徽章指示器无论视口缩放均保持固定像素尺寸。

### 迭代指南
1. 首先锁定表面极性（深色运营 vs. 浅色管理），再调整强调色和状态色。
2. 保持强调蓝的用途克制；在安全 UI 中，蓝色不得与威胁红或状态绿竞争——严格保留给操作、导航和信息语义。
3. 按以下顺序调整字体：正文可读性（12px）→ 标题层级（14–32px）→ 数值显示（DIN Alternate）。
4. 按组件类别应用圆角（2px 内容 → 4px 控件 → 6px 嵌套 → 8px 外层），严格遵循嵌套法则。
5. 从管理表面向运营表面过渡时，刻意增加信息密度。
6. 每次字体修订后验证 `tabular-nums` 启用状态下数据表对齐是否正常。
7. 每次布局修订后验证页面模式：按钮是否在标题下方左侧、筛选器是否在右侧、表格是否有 16px 内边距、翻页器是否在右下。

### 已知缺口
- 动画与微交互规范（过渡时长、缓动曲线、加载骨架屏）尚未在 Token 系统中编码。`resource/animation/` 目录当前为空。
- 1280px 以下的响应式行为（平板和移动端断点）需要为安全运营工作流进一步细化。
- 部分交互微状态（拖拽反馈、多选高亮、行内编辑过渡）因模块而异，尚未作为通用系统 Token 呈现。
- 深色模式渐变卡片处理在预览页面中使用了硬编码 rgba 值，应迁移至语义 Token。
- 图标系统的填充、双色和多色风格缺乏除默认线性模式之外的正式使用指南。
- 安全域的攻击结果色（`--color-state-attack-*`）和任务状态色（`--color-state-task-*`）Token 已在 Colors.md 中定义但尚未在 demo 模板中完整呈现。
